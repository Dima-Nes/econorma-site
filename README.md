# ЭкоНорма — новая версия сайта (econorma.by)

Статический сайт без сборщиков и внешних зависимостей: готов к размещению на хостинге в Республике Беларусь (hoster.by, activecloud.by, nginx). Все шрифты (`Golos Text`, `PT Mono`, `PT Serif`) размещены локально в `assets/fonts/` — сторонние запросы на Google Fonts отсутствуют (соответствует Закону РБ № 99-З).

## Локальный просмотр

```bash
python3 -m http.server 8770 --directory 07_Сайт_ЭкоНорма
```

Затем откройте `http://localhost:8770/` в браузере.

## Структура

- `index.html` — главная страница (досье образцов, услуги, просмотрщик А4, порядок работ, самопроверка, классификатор отходов, цены, специалисты, сведения для тендерных комиссий, частые вопросы, форма КП)
- `politika.html`, `soglasie.html` — политика и согласие на обработку персональных данных (Закон № 99-З)
- `404.html` — страница ошибки 404
- `css/fonts.css`, `css/tokens.css`, `css/docs.css`, `css/styles.css` — дизайн-система и стили А4-документов с поддержкой печати (`@media print`)
- `js/docs-data.js` — 6 обезличенных образцов документации + Квалификационная справка + Чек-лист для завхоза
- `js/app.js` — логика переключения образцов, модальный просмотрщик, печать, самопроверка, копирование реквизитов и форма заявки

## Перед публикацией в продакшн

1. Подключить обработчик формы: в `js/app.js` задать URL в константе `LEAD_ENDPOINT` (Telegram-бот или CRM). Пока URL пуст, форма формирует готовый текст заявки с кнопками «Открыть в почте» и «Скопировать текст заявки».
2. Проверить и согласовать с юристом тексты `politika.html` и `soglasie.html` (убрать жёлтую плашку «Редакция для проверки юристом»).
3. Подтвердить финальный состав специалистов в блоке `#team` и в `js/docs-data.js` (при появлении портретных фотографий и письменного согласия экологов).
4. Сверить коды отходов и формулировки нормативных актов в `js/docs-data.js` с актуальными редакциями на `pravo.by`.
